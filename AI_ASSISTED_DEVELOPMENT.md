# AI-assisted development disclosure

The project was developed with assistance from generative AI tools. The human maintainer specified the research goals, requested software changes, reviewed outputs, and performed real-world XRD testing (including the COD silicon phase-screening and persistence tests).

Source code and documentation may contain AI-assisted implementations and need the same independent testing and security review as any other scientific software. Claims of fully automated scientific validation are not made.

The source-code license is applicable only to original application code that the maintainer is authorized to release. Copyright, data and redistribution terms of third-party dependencies and datasets are separate.
